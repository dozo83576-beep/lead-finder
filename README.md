# Lead Finder

Локальный инструмент для поиска компаний, которым может понадобиться новый сайт или техническая доработка существующего.

Инструмент использует бесплатные данные OpenStreetMap, проверяет объективные признаки сайта, сохраняет историю в SQLite и готовит персональные обращения для мессенджера, email и звонка. Автоматической рассылки нет.

## Установка

Требуется установленный Python 3.14.

```powershell
cd D:\Freelance
py -3.14 -m pip install -r requirements.txt
```

## Запуск

```powershell
py -3.14 -m streamlit run app.py
```

Streamlit покажет локальный адрес, обычно `http://localhost:8501`.

Для первой проверки включите **Тестовый запуск без сети** и нажмите **Найти и проверить**. Dry Run показывает три тестовых лида и ничего не записывает в базу.

## Рабочий сценарий

1. Укажите город.
2. Выберите одну из десяти ниш или вариант **Другая ниша**.
3. Для другой ниши обязательно укажите ключевое слово.
4. Выберите лимит от 1 до 200 и запустите поиск.
5. Отфильтруйте лиды, откройте карточку и скопируйте подходящее обращение.
6. Сохраните статус и заметку либо скачайте текущую выборку как CSV/XLSX.

Повторный поиск обновляет автоматические данные, но сохраняет ручной статус и заметку.

## Импорт своих данных

Поддерживаются CSV и XLSX. Обязательна только колонка `name`.

Допустимые колонки:

```text
name,category,city,address,phone,email,social,website,source,source_url
```

## Необязательный PageSpeed

Без ключа PageSpeed инструмент полностью работает, но не выставляет баллы за мобильную скорость.

```powershell
$env:PAGESPEED_API_KEY="ваш_ключ"
py -3.14 -m streamlit run app.py
```

## Локальные данные

- `leads.db` — история лидов, статусы и заметки;
- `lead_finder.log` — этапы запуска и ошибки без телефонов, email и заметок.

Для резервной копии достаточно закрыть приложение и скопировать `leads.db`.

## Проверка

```powershell
py -3.14 -m unittest discover -s tests -v
py -3.14 -m compileall lead_finder.py storage.py app.py
```

## Ограничения

- Полнота компаний и контактов зависит от наполнения OpenStreetMap.
- Автоматически оцениваются только проверяемые технические признаки. Субъективная оценка дизайна не выполняется.
- Яндекс и 2ГИС не используются: бесплатные условия не подходят для локальной сохраняемой базы контактов.
- Публичные Nominatim и Overpass предназначены для небольших запросов. Лимит приложения ограничен 200 записями.
